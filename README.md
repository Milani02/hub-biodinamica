# Hub Biodinâmica

Portal central de acesso aos sistemas internos e institucionais do Grupo Biodinâmica (Biodinâmica, Oraltech, Injecta), reunindo em uma única página os links para sistemas de RH, suporte, portal do colaborador, sites institucionais e redes sociais das marcas do grupo.

## Funcionalidades

- Acesso rápido a sistemas internos (RH, ChatBio, GED, SAC)
- Portal do colaborador e painéis de controle (Ciosp, WebChamado)
- Links para sites institucionais e lojas das marcas do grupo
- Atalhos para as redes sociais de cada marca (Instagram, Facebook, YouTube, LinkedIn)

## Stack

- [Next.js](https://nextjs.org/) 16 (App Router) + React 19 + TypeScript
- Tailwind CSS 4
- Framer Motion para animações
- Spline (`@splinetool`) para elementos 3D interativos

## Como rodar localmente

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Scripts

| Comando | Descrição |
